🚀 Quick Start: Connect to Your Account
1 Sign In / Claim Server

Open the Umbrel Terminal app or SSH into your Umbrel and run this command to log in:

docker exec -it openbot-app_openbot_1 openbot login

Or with Umbrel CLI:

umbrel app compose openbot-app exec openbot openbot login
2 Connect Mobile App (iOS / Android)

To pair the OpenBot mobile app, generate a terminal QR code:

docker exec -it openbot-app_openbot_1 openbot mobile-connect
3 Check Server Status

Verify that the background OpenBot server is healthy and connected:

docker exec -it openbot-app_openbot_1 openbot status
